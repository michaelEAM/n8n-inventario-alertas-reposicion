## 3. Reto aplicado al proyecto

### Funcionalidad trabajada

**Proceso:** Gestión de inventario.
Se implementó un flujo de inventario en n8n para el encargado del inventario. Entrada: cantidad disponible y stock mínimo. El Switch clasifica el estado para facilitar la reposición.

### Criterios de aceptación

- [x] Stock crítico cuando las existencias están en un nivel muy bajo
- [x] Reponer pronto cuando el stock se acerca al mínimo definido.
- [ ]Stock suficiente cuando las existencias superan el límite.

### Archivos o componentes modificados

![[Pasted image 20260831222612.png]]

Workflow de n8n: Manual Trigger -> Edit Fields -> Switch.
Nodos de salida: estado del inventario según la clasificación.
## 4. Decisiones técnicas

| Decisión                 | Razón                                                                       | Alternativa descartada                 |
